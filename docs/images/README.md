# Screenshots

Drop here the screenshots referenced by the main `README.md` and reused for the
Microsoft Marketplace listing in Partner Center.

- Format: **PNG**, **1366×768 minimum** (16:9), light theme unless stated.
- Use anonymised or fictional user data (no real employee photos or emails).
- Keep the file names exactly as listed below so the README renders correctly.

| File | Content |
| --- | --- |
| `card-view.png` | Card (trombinoscope) view with several members |
| `list-view.png` | List view with sortable columns and the pager |
| `search-filters.png` | Search box with one or two multi-select filters open |
| `detail-panel.png` | Member detail panel with the contact actions |
| `property-pane-display.png` | Property pane – *Display* group (view, sort, items per page) |
| `property-pane-fields.png` | Property pane – field configuration (drag and drop) |
| `dark-theme.png` | Card view rendered with a dark SharePoint theme |

For the Marketplace submission, 2 to 5 screenshots are enough (reuse the first
five above).
